# M4 抖音采集 · 本机使用说明

> 目标：把抖音（或任意短视频）变成可语义检索的文字笔记，进入「MyKnowledge」个人知识库。
> 设计取舍：**主路径 = 本地视频文件模式**（你把视频存到文件夹，我们负责转写+关键帧+入库），
> 不依赖破解抖音反爬，最稳。分享链接自动抓取作为进阶接口预留（抖音强风控，默认不启用）。

---

## 一、一次性安装依赖

```bash
cd /d "D:/workbuddy worktool/贾维斯/pipeline"
pip install faster-whisper opencv-python-headless imageio-ffmpeg
# 国内镜像（若默认源慢）：
pip install -i https://mirrors.aliyun.com/pypi/simple/ faster-whisper opencv-python-headless imageio-ffmpeg
```

- `imageio-ffmpeg`：自带 ffmpeg 二进制（抽音频、抽关键帧用），**零额外配置**。
- `faster-whisper`：本地语音转写（CPU 也能跑，int8 量化）。
- `opencv-python-headless`：提取关键帧（无界面依赖）。

> ⚠️ **首次转写会自动从 huggingface 下载模型权重**（默认 `base`，中文可用 `small` 提精度）。
> 若你的网络访问 huggingface 不畅，会看到「ASR 暂未生成」的降级提示——此时视频仍会入库，
> 关键帧也在；装好模型权重后重跑 `collect douyin` 即可补全转写（按视频绝对路径幂等，不会重复）。

## 二、准备视频文件夹

在 `D:/Desktop/MyKnowledge/` 下新建 `douyin_videos/` 文件夹，把想入库的抖音视频放进去：

```
D:/Desktop/MyKnowledge/douyin_videos/
├── 如何搭建个人知识库.mp4
├── 基层治理小技巧.mp4
└── 健康养生#科普.mp4        # 文件名里的 #话题 会自动变成标签
```

可选：给某个视频配一个同名 `.txt` 作为标题/说明，例如 `如何搭建个人知识库.txt`，
首行作为笔记标题，全文作为笔记开头说明。

## 三、修改配置 `pipeline/config/sources.yaml` 的 douyin 段

```yaml
douyin:
  enabled: true                  # 改成 true 即可开启
  cron: "30 4 * * *"             # 每天 04:30 自唤醒（与 web/小红书错开）
  local_dir: "D:/Desktop/MyKnowledge/douyin_videos"   # 上面的视频文件夹
  work_dir: "D:/Desktop/MyKnowledge/douyin_work"      # 处理中间产物（关键帧持久化到此）
  asr_model_size: "base"         # tiny/base/small；显存够用 small 更准
  language: "zh"
  keep_audio: false              # true 则保留抽取的 wav（占空间）
  keyframes: 4                   # 均匀提取几张关键帧
  # vision_model: ""             # 可选：本地视觉模型给关键帧配文；空=仅留附件
  keywords: ["知识科普"]
  share_links: []                # 进阶：分享链接自动抓取（默认不启用，见下）
```

## 四、运行

```bash

# 仅入库、不调云端摘要（最快验证）

# 一键启动看板（含自唤醒调度）
python run.py --web
```

## 五、入库后长什么样

每条抖音视频 → 一条 `LITERATURE` 类型笔记：

```
# 如何搭建个人知识库          ← 来自文件名或同名 .txt

来源文件：D:/Desktop/MyKnowledge/douyin_videos/如何搭建个人知识库.mp4

## 语音转写（ASR / faster-whisper）
[00:00] 大家好，今天讲怎么搭建个人知识库……
[00:23] 第一步是明确目标……

## 关键帧（多模态附件）
- 帧1 frame_001.jpg
- 帧2 frame_002.jpg
...
```

- **语音转写**提供可语义检索的正文（核心）；
- **关键帧**以附件形式落库（`Note.attachments`，路径存于 `notes.attachments` 列 + 原文 frontmatter），可视化回看画面；
- 笔记用视频**绝对路径**做幂等 ID，重跑同文件只覆盖、不重复。

## 六、进阶：分享链接自动抓取（默认不启用）

抖音 web 端强风控（签名参数 X-Bogus、设备指纹、登录墙），通用下载工具极不稳定。
当前版本**仅预留接口**：在 `sources.yaml` 填 `share_links: [...]` 并配置 `cookie_path` 后，
采集器会打印明确提示而不自动抓取，避免在本机误触发风控。

如需真正启用，建议路径：Playwright + 你的登录态 Cookie 打开分享页 → 拦截网络请求拿到视频流直链
→ httpx 下载 → 走上面的 `core/video.py` 处理。这块按需在 M4.1 单独做，且务必低频、个人自用。

## 七、合规提醒

- 仅采集**你自己下载/关注的**内容用于个人知识管理，勿批量搬运他人作品。
- 抖音内容受版权与平台规则约束，个人学习整理请遵守平台条款与《著作权法》。
- 关键帧/音频落盘在本地 `MyKnowledge`，不上传第三方。

## 八、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `未找到 ffmpeg` | 没装 `imageio-ffmpeg` → `pip install imageio-ffmpeg`；或系统装 ffmpeg 并加 PATH |
| `ASR 暂未生成` | whisper 模型权重未下载（huggingface 网络问题）→ 本机直连网络重跑，或手动下载模型 |
| 关键帧为空 | opencv/ffmpeg 缺失 → 装 `opencv-python-headless` |
| 视频没被采集 | 检查 `local_dir` 路径、`enabled: true`、文件后缀（支持 mp4/mov/m4v/webm/avi/mkv/flv/wmv） |
| 重跑出现重复笔记 | 不会——按视频绝对路径幂等覆盖；若换了文件名/位置会视为新条目 |
