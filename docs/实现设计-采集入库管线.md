## 1. 设计覆盖边界

- **本期做**：调度自唤醒 → 三类采集器（先 web，后 XHS/Douyin 桩）→ 解析清洗 → 本地抽取结构化 →（仅摘要）DeepSeek → 入库（原文 + bge-m3 向量 + Chroma）→ Web 看板。
- **本期不做**：语音链路（属并行线）、微信、跨设备、知识库对外发布。
- **关键约束落地**：本地 Ollama `qwen3-14b` 负责抽取/结构化/嵌入兜底；**DeepSeek `deepseek-flash` 仅用于生成摘要**，不用于抽取（保持"本地优先、云端仅摘要"边界）。

## 3. 数据模型（schema）

### 3.1 内存对象（`core/models.py`）
```python
@dataclass
class RawItem:
    item_id: str          # hash(url + captured_at)
    source: str           # "web" | "xiaohongshu" | "douyin"
    url: str
    title: str
    content: str          # 清洗后的正文/转写文本
    captured_at: datetime
    meta: dict            # 来源特有字段（作者、点赞、时长等）

@dataclass
class ProcessedItem:
    raw: RawItem
    structured: dict      # 本地模型抽取的结构化字段
    summary: str          # DeepSeek 摘要
    embedding_id: str
```

### 3.2 SQLite 任务状态（`core/db.py`，对应 Aivy「Mission 长任务」）
```sql
CREATE TABLE tasks (
    task_id    TEXT PRIMARY KEY,   -- 一次采集任务的实例 id
    source     TEXT,
    url        TEXT,
    status     TEXT,               -- pending|running|done|failed
    retries    INT DEFAULT 0,
    error      TEXT,
    created_at TEXT,
    updated_at TEXT
);
CREATE TABLE items (
    item_id    TEXT PRIMARY KEY,
    source     TEXT,
    url        TEXT,
    title      TEXT,
    raw_path   TEXT,               -- data/raw/<id>.md
    summary    TEXT,
    created_at TEXT
);
```
- 失败按 `retries` 跨天续跑（自唤醒下一轮重试），实现"Mission 长任务追踪"。

## 6. Web 看板（`api/`）

- **后端**：FastAPI，端口 `http://localhost:8000`
  - `GET /stats` → 总条目数、各源今日采集数、失败数
  - `GET /tasks?status=` → 任务列表（对应任务看板）
  - `GET /items?q=` → 语义检索结果
  - `POST /trigger?source=` → 手动触发某源采集（CLI 兜底同功能）
- **前端**：`static/index.html` 单页，轮询上述接口，表格展示任务流/失败重试/统计。
- CLI 兜底：`python cli.py status` / `python cli.py trigger --source web`

## 7. 安全与合规

- **DeepSeek Key**：仅存于环境变量 `DEEPSEEK_API_KEY`（`.env.example` 模板），配置与代码不写明文。
- **Cookie（XHS/Douyin）**：本地 `data/cookies/` 存登录态，建议用用户主目录密钥或简单加密；不入库、不提交。
- **合规**：个人非商用、限频、不转售；遵守 robots 与平台条款；XHS/Douyin 启用后仅采集本人关注/公开内容。

## 9. 待确认 / 风险（实现前）

1. **Chroma vs 纯 SQLite+向量**：阶段一 Chroma 足够；若你日后要元数据过滤更强，可换 Qdrant（已留 `vectorstore.type` 开关）。
2. **whisper 选型**：`faster-whisper` 比原版快很多、CPU/GPU 均可；中文质量需在 M4 实测。
3. **DeepSeek 实时单价**：PRD §9 注明官方 USD 与中文媒体 RMB 差约 10×，**实现前请在 `platform.deepseek.com/usage` 核对一次**。
4. **进程驻留方式**：`run.py` 常驻（开发期）；长期可改为 Windows 任务计划程序触发而非常驻（更省资源）——留作后续决定。
