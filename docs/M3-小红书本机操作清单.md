# M3 小红书采集 · 本机操作清单

> 代码已写好并经离线验证（`collectors/xiaohongshu.py`：Playwright 真实浏览器 + 登录态 Cookie + 单并发限频 5–15s + 反检测）。

## 1. 安装 Playwright + Chromium（一次性）
```bat
cd /d "D:/workbuddy worktool/贾维斯/pipeline"
python -m pip install playwright
python -m playwright install chromium
```
- 第二步会下载 Chromium（约 150MB+），**需要能访问 Playwright CDN**。若公司/校园网下不动，可换国内镜像：
  ```bat
  set PLAYWRIGHT_DOWNLOAD_HOST=https://playwright.azureedge.net  （或 https://npmmirror.com/mirrors/playwright）
  python -m playwright install chromium
  ```
- 验证：`python -c "from playwright.sync_api import sync_playwright; print('ok')"` 不报错即可。

---

## 2. 配置采集目标（改 `config/sources.yaml`）
打开 `config/sources.yaml`，找到 `xiaohongshu:` 段：

- **`note_urls`**：把示例链接换成你真正想入库的小红书笔记链接（每条一行）。推荐用「笔记详情页链接」，最稳、风控最低：
  ```yaml
  note_urls:
    - "https://www.xiaohongshu.com/explore/你的笔记ID1"
    - "https://www.xiaohongshu.com/explore/你的笔记ID2"
  ```
- **`cookie_path`**：保持 `data/cookies/xhs.json`（登录态会自动存这里，别提交到 git）。
- **`headless`**：保持 `true` 即可。首次没 Cookie 时，代码会自动改用「可见浏览器」让你登录，登录完再切回。
- **`keywords`**：**保持 `[]` 不要开**。关键词搜索是高风险模式（逐条抓搜索结果，易触发风控）。先用「指定笔记 URL」模式把链路跑通。
- 限频 `min_delay/max_delay`：默认 5–15 秒随机延时，单并发串行，**宁慢勿封**。

---

## 3. 首次运行 = 登录 + 采集
```bat
cd /d "D:/workbuddy worktool/贾维斯/pipeline"
python cli.py collect xiaohongshu
```
- 首次无 Cookie → 自动弹出**可见浏览器**打开 xiaohongshu 登录页。
- 用手机扫码 / 手机号登录你的账号，登录成功后**回到终端按回车**。
- 程序自动把登录态存到 `data/cookies/xhs.json`（之后复用，不用每次登录）。
- 接着按 `note_urls` 逐条抓取（每条间隔 5–15 秒），解析标题/正文/标签/作者并入库。
- 入库后默认会调 DeepSeek 生成摘要（走 `DEEPSEEK_API_KEY`）；若只想快速验证、跳过云端摘要，加 `--no-summary`：
  ```bat
  python cli.py collect xiaohongshu --no-summary
  ```

## 5. 接入每日自唤醒（可选）
`run.py --web` 或 `run.py` 常驻即可。调度按 `sources.yaml` 的 `cron`（默认每天 **04:00**）自动跑 `xiaohongshu`，与 web（03:00）错开。
- 长期驻留建议用 Windows 任务计划程序定时触发，而非一直常驻（更省资源）。
- 定时任务走 `headless: true`（无界面），前提是 `data/cookies/xhs.json` 仍有效。

## 6. 常见问题排查
| 现象 | 原因 / 处理 |
|---|---|
| `浏览器启动失败（多半是 Chromium 未下载）` | 回到第 1 步 `python -m playwright install chromium`，确认下载完成 |
| `未找到登录态，进入交互登录模式` 后登录失败 | 删除 `data/cookies/xhs.json` 重跑第 3 步重新登录 |
| 任务 `failed`，err 含「解析为空」 | 小红书页面结构变动或 Cookie 失效（需重新登录）；可保存该笔记 HTML 用 `parse_note_page` 离线复现 |
| 任务 `failed`，err 含「登录墙」 | Cookie 过期，删 `xhs.json` 重新登录 |
| 抓取后内容乱码/为空 | 检查 `sources.yaml` 里 web 段的 `verify_ssl`（生产机保持 `true`）；小红书本源不受影响 |
| 想要更多笔记 | 往 `note_urls` 加链接；**不要开 `keywords` 搜索**（高风险）。如需批量，务必降低频率 |
